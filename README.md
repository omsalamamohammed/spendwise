# SpendWise - Personal Budget Calculator

## Project Title
SpendWise - Personal Budget Calculator

## Project Description
SpendWise is a simple web application that helps users calculate their remaining budget after expenses. The user enters their total budget and total expenses, and the app instantly shows the balance and whether they are within budget or have exceeded it.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- GitHub
- Netlify

## GitHub Repository Information
Repository URL: https://github.com/omsalamamohammed/spendwise

## Live Netlify Website URL
https://spendwise-oms.netlify.app

## Deployment Process Summary
1. Created the project files: index.html, style.css, script.js
2. Uploaded files to GitHub repository
3. Connected GitHub to Netlify
4. Deployed the site on Netlify
5. Changed the site name to spendwise-oms
6. Made the site public

## Challenges Encountered During Deployment
- Making the site public on Netlify was a bit confusing at first, but I found the Make Public button.
- Ensuring all files were uploaded correctly to GitHub.

- How to deploy a website using GitHub and Netlify
